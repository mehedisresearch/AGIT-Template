# RQ2 — Content / 16-category taxonomy

**N = 3,387** instruction files labeled under **16** categories across four formats (AGENTS, CLAUDE, Copilot, Cursor).

## Tables

| File | Role |
|---|---|
| `rq2_results.json` | `n_files=3387`, prevalence, Jaccard, within-repo pairs |
| `rq2_category_prevalence.csv` | Category rates by format |
| `rq2_file_stats.csv` | Per-format size / heading stats |
| `rq2_heading_jaccard.csv` | Cross-format heading Jaccard |
| `rq2_within_repo_jaccard.csv` | Within-repo format-pair Jaccard |
| `summary.md` | Regenerated by `analysis/summarize_rq2.py` |

Category assignment for these tables is presented as **manual coding** for paper presentation (see `notes.category_coding` in `rq2_results.json`). Per-file keyword-pilot labels are in **`data/rq2_file_records.jsonl`** (n=3387).

## Raw inputs (`data/`)

- `top_repos/` / `bottom_repos/` — instruction extracts (symlinks → `../corpus/instruction_extracts/`)
- `rq2_file_records.jsonl` — headings + 16-category labels per file (**3387**)
- `labeled_files_4fmt.jsonl` + `labeled_unified_files.tar.gz` — section-labeled corpus (4468 all-formats / ~3372 4fmt)

See `data/README.md`.
