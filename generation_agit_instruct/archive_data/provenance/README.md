# Provenance corpora (post–four-format filtration)

These files are the **2,853**-pair AGIT-Instruct corpora after RQ2 four-format filtration (≥2 sections). They are **not** the official train/val/test benchmark files.

| File | Role |
|---|---|
| `agit_instruct_pairs_2853.json` | Instruct pairs + repo summaries (= `agit_instruct_4fmt_with_summary.json`) |
| `generic_intent_files_2853.json` | Generic-intent targets (= `generic_files_4fmt.json`) |

Official splits: `../train.json`, `../val.json`, `../test.json` (see `../BENCHMARK.md`).
